# Angie's World — Plan and Change Log

## 1. Original Plan

My goal was to create a personal website called Angie's World using HTML and CSS. I wanted it to feel cozy, cute, and welcoming, with a kawaii gamer-girl aesthetic. I planned to use a lakeside scene, a cat inspired by my calico tabby, white daisies, and a soft sage-green color palette.

I also wanted the website to be organized, visually appealing, and responsive so that the content would fit different screen sizes.

## 2. What I Asked the AI Agent to Do

I asked the AI agent to help me build and improve my HTML website. My requests included creating the visual design, adjusting the colors and containers, improving the layout, and making the website work better on different screen sizes.

I also asked for changes to the background, decorative elements, and spacing so the overall design would feel more consistent.

## 3. Changes I Made Along the Way

As I worked on the website, I refined the design instead of keeping the first version exactly as it was.

- I developed the cozy lakeside theme with a cat, daisies, and a picnic-style scene.
- I worked on making the background a warm cream color.
- I adjusted the containers to use darker green tones for contrast.
- I requested layout and spacing improvements so the content would fit more naturally inside the containers.
- I worked on making the website more responsive for different screen sizes.

## 4. Decisions and Ideas I Changed

I decided to refine the colors and layout as the website developed. I moved toward a cream background with darker green containers rather than relying only on lighter green tones.

I also prioritized responsive sizing and better spacing so that the website would be easier to view on different devices. Some design details changed during the process as I compared versions and decided what looked best.

## 5. What I Learned

I learned that building a website involves more than writing HTML. The colors, spacing, images, containers, and layout all affect how the final website looks and feels.

I also learned that I can work with an AI agent to improve a project through repeated requests and revisions. I had to review the results, decide what I liked, and explain what I wanted changed. This helped me understand the importance of testing and refining a website rather than expecting the first version to be perfect.
