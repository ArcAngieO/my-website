Angie's World — cozy sage-green gaming website

Files:
- index.html: website layout and content
- style.css: responsive grid layout, botanical decoration, and colors
- angie-gamer.png / angie-portrait.png: girl illustrations
- cozy-landscape.jpg: storybook landscape backdrop
- plant-*.png, cat-planter.png, flower-*.png, mushrooms.png, sage-bow.png: decorative botanical sticker assets

Preview: open index.html in your browser. Keep all files together in one folder.

To publish updates to GitHub, run from this folder:
  git add .
  git commit -m "Add botanical reference styling"
  git push
